# T4 抄录记录：MT6835 SPI 读角事务

## 背景

计划要求角度寄存器映射从 MT6835 数据手册抄录，禁止编造。执行时
（2026-09-24）官方手册直链已失效（magntek.com.cn 首页指向的
`/upload/pdf/202403/MT6835_Rev.1.3_中文版.pdf` 返回 404；镜像站与
archive.org 在本网络不可达）。改从实测硬件的成熟开源驱动
SimpleFOC `Arduino-FOC-drivers` 的 `MT6835.h/.cpp`（MIT）抄录，
交叉核对寄存器表。**上板首读是帧格式的最终校验关卡**（见最终
上板清单 T4-①）：若 raw21 读数恒 0 或明显不合理，以模块随附的
纸质/电子手册为准复核本页抄录。

## 抄录内容（SPI）

- 接口：4 线 SPI，**MODE3**（CPOL=1，第 2 边沿采样），MSB 先行。
  手册标称最高时钟 16 MHz；本项目 Kconfig 默认 1 MHz（保守）。
- 指令帧（24 bit，MSB 先行）：`{cmd:4 | addr:12 | data:8}`。
- 操作码：READ=0b0011，WRITE=0b0110，PROG=0b1100，ZERO=0b0101，
  **ANGLE=0b1010**。
- 角度寄存器（连续 4 字节）：`ANGLE1=0x003、0x004、0x005、0x006`。
  其他：USERID=0x001、ABZ_RES=0x007/0x008、ZERO=0x009/0x00A、
  OPTS0–5、NLC 表基址 0x013、CAL_STATUS=0x113。
- **读角事务（本项目每毫秒执行一次）**：CS 拉低，单次 48 bit
  （6 字节）传输：
  - 主发：`[0] = 0xA0`（OP_ANGLE<<4），`[1] = 0x03`（ANGLE1），
    `[2..5] = 0`；
  - 从回：`[2] = ANGLE[20:13]`，`[3] = ANGLE[12:5]`，
    `[4] = ANGLE[4:0]<<3 | STATUS[2:0]`，`[5] = CRC8`；
  - `raw21 = (rx[2]<<13) | (rx[3]<<5) | (rx[4]>>3)`。
- STATUS：bit0 过速、bit1 磁场弱、bit2 欠压（本项目仅记日志）。
- CRC8：多项式 `x^8+x^2+x+1`（0x07）、初值 0x00、无最终异或；
  输入为 3 个 8 bit 块（angle>>13、(angle>>5)&0xFF、
  (angle<<3)&0xFF | status）。**首版不启用校验**，首读验证帧
  格式后再评估。

## 换算常量（本组件）

- 21 bit 全量程 = 2 097 152 count/圈。
- µrad 取整数 π：π = 3 141 592，2π = 6 283 185（floor）。
- `urad = raw21 × 6283185 / 2097152`（u64 中间量），减零位后
  wrap 到 ±π；半圈 raw = 2^20 映射 +π，(2^20, 2^21) 映射负角。
- 角速度：`mrad/s = Δcounts × 6283185 / 2097152 / window_ms`
  （µrad/ms 恰为 mrad/s）。
