## 接口与时序

MT6835 使用四线 SPI 模式 3（CPOL=1、CPHA=1），MSB 先行。
CSN 拉低后，主机必须至少等待 100 ns，才能产生第一个 SCK 下降沿；
最后一个 SCK 上升沿到 CSN 上升沿至少间隔半个 SCK 周期。

[SPI 帧层](../../components/mt6835/mt6835_hw.c)通过 ESP-IDF 的
`cs_ena_pretrans` 配置建立等待。该配置覆盖
[BSP 配置](../../components/bsp/Kconfig)允许的整个时钟范围；默认时钟为 1 MHz。
驱动采用全双工数据阶段发送完整帧，硬件 command/address 阶段均为零，
与 ESP32-S3 的 CS 建立等待配置兼容。

CSN 下降沿使内部角度寄存器 0x003～0x006 锁存，因此一次 CS 周期内读取的数据属于同一快照。
读完一组后继续提供时钟，可以继续读取下一组；固件每次事务只读取一组。

## 连续读角度帧

SPI 指令包含 4 位操作码和 12 位地址。`0011` 读取单个寄存器，
`1010` 从 0x003 开始连续读取角度寄存器。正式固件使用一次 48 位事务：

| 字节索引 | 主机发送 | 主机接收 |
| --- | --- | --- |
| 0 | `0xA0`：操作码与地址高位 | 此阶段 MISO 为高阻，不参与解析。 |
| 1 | `0x03`：地址低位 | 此阶段 MISO 为高阻，不参与解析。 |
| 2 | `0x00` | `ANGLE[20:13]` |
| 3 | `0x00` | `ANGLE[12:5]` |
| 4 | `0x00` | `ANGLE[4:0] << 3 \| STATUS[2:0]` |
| 5 | `0x00` | 器件返回的 `CRC[7:0]`。 |

`raw21 = (rx[2] << 13) | (rx[3] << 5) | (rx[4] >> 3)`。
STATUS bit0 表示转速过快，bit1 表示磁场弱，bit2 表示欠压；状态变化由设备层记录日志。

CRC 多项式为 X⁸+X²+X+1（`0x07`），初值为 `0x00`，无最终异或。
校验输入为 `ANGLE[20:0] << 3 | STATUS[2:0]`，共 24 位，最高位先进入。
驱动拒收 CRC 不符的帧，并拒收角度、状态和 CRC 均为零的帧；失败时保留接收帧供诊断。
全零只能说明本次接收到了零，不能仅凭这一帧确定器件未连接。

## 角度换算

换算常量由 [mt6835_urad.h](../../components/mt6835/include/mt6835_urad.h) 定义。
21 位角度覆盖一整圈；换算使用 64 位中间量，减去零位后环绕到 ±π。
[宿主换算测试](../../host_tests/mt6835_urad_test.c)使用手算向量验证边界。
