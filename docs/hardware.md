# 硬件参数确认清单 · 新板（硬件改版 2026-10-17）

> 项目：ESP32-S3 单轴运动控制器（cartpole 小车倒立摆）
> 初版定稿 2026-09-11 · 引脚修订 2026-09-12 · 供电压档 12V→20V 2026-10-16 ·
> **硬件改版 2026-10-17**：小车编码器 AS5600→MT6835（板载）、摆角编码器改外接 MT6835、
> PD 诱骗芯片 CH224K→CH224Q、烧录/日志切原生 USB、协议通道 UART1→UART0、新增按键/LED/总线电压检测。
> 本文件为 BSP 及后续全部任务的硬件事实来源。旧板（AS5600/CH343P 时代）记录已被本版替换。

## 1. USB-C 拓扑与 PD 供电

- **单口** USB-C（充电+数据共用）：
  - CC 线 → **CH224Q** PD 诱骗，CF1 引脚外接 **120 kΩ** 电阻定档诱骗 **20V**；
    后续可通过 I2C 修改诱骗电压档（本版固件仅预留，不做 I2C 调档）。
  - D+/D−（io20/io19）→ ESP32-S3 **原生 USB（USB-Serial/JTAG）**：烧录与日志。
- VM（20V）直供 TMC2209；VBUS → TPS62933 降压（输入 3.8–30V）→ 3.3V 系统供电。
- **总线电压检测**：io4（ADC），分压上臂 20 kΩ / 下臂 2.7 kΩ。
  换算系数 22.7/2.7 ≈ 8.407；20V 总线时 ADC 端约 2.38V（量程内）。
  用途：回读确认 PD 诱骗是否成功（12V/20V 档位差 8V，判定裕量充足）。
- ⚠️ 插电脑调试：电脑 Type-C 口通常不输出 20V 档，总线回落 5V——
  逻辑电（3.3V，TPS62933 输入下限 3.8V）与烧录/日志正常，但 VM=5V 低于
  TMC2209 正常驱动要求，**不得 ENABLE 电机**。
- 上电首检（供电压档核查，2026-10-16 记录沿用到新板）：3.3V 轨电压正常、
  TMC2209 散热板温升可接受、io4 回读 ≈20V 确认诱骗成功。

## 3. 引脚分配表（新板）

| 功能 | GPIO | 备注 |
|---|---|---|
| **UART0 TX/RX**（主机协议通道，飞线直连） | **43 / 44** | 协议通道从 UART1（41/42，经 CH343P）整体迁移；CH343P 已随改版移除；3.3V TTL，共地 |
| **原生 USB D−/D+**（烧录/日志） | **19 / 20** | USB-Serial/JTAG；旧板 19/20 未引出的状态就此解除 |
| TMC2209 单线 UART TX | 17 | 经板载 1kΩ 接 PDN_UART 节点 |
| TMC2209 单线 UART RX | 18 | 直连 PDN_UART 节点 |
| TMC2209 STEP | 5 | |
| TMC2209 DIR | 6 | |
| TMC2209 EN | 21 | 低有效 |
| TMC2209 DIAG1 | 16 | |
| **小车编码器 MT6835（板载）** | SCK=12 MOSI=11 MISO=13 CS=10 | SPI 控制器一：测小车位置（接替旧板 AS5600 职责） |
| **摆角编码器 MT6835（外接）** | SCK=47 MOSI=48 MISO=38 CS=14 | SPI 控制器二：测摆杆角度；外接板供电由主控板提供 |
| I2C SDA / SCL（CH224Q） | 8 / 9 | 引脚沿用旧板 I2C；总线现挂 CH224Q（I2C 调压预留） |
| VBUS ADC | 4 | 分压 20k/2.7k，见 §1 |
| 按键 but1 / but2 / but3 | 7 / 2 / 1 | 行为语义待定义，固件先做驱动层 |
| LED | 15 | 心跳/指示，语义待定义 |
| BOOT | 0 | 常规 |
| UART1（原协议通道） | 41 / 42 | **不再使用**（随 CH343P 移除而废弃） |

SPI 分配：两编码器为两条独立 SPI 总线（两组引脚无共享），启用两个不同 SPI 控制器。

## 4. 编码器安装

| 项目 | 实际值 |
|---|---|
| 小车位置 | 板载 MT6835，21 bit；磁铁装电机尾轴（沿用原 AS5600 安装位） |
| 摆杆角度 | 外接 MT6835 模块，21 bit，主控板供电；磁铁装摆杆转轴 |
| 磁铁规格/间隙/同心度 | **待补**（旧板 AS5600 为 6mm×3mm 径向充磁、0.5mm 间隙；MT6835 磁铁参数以实物为准） |

AS5600 芯片已从板上去除；as5600 源码组件保留在仓库中（后续复用或切换，不再接线）。
