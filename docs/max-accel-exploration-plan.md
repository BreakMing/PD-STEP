# 最大加速度实测方案（VM 20V 基线）

- 定稿：2026-10-16
- 目的：测定固件与电机组合在固定驱动条件下，电机轴不失步的「巡航速度 × 加速度」可行域边界
- 关联：[hardware.md](hardware.md)（硬件事实来源）、[protocol.md](protocol.md)（线协议）、cartpole 仓库 `deploy/v2/sim2real-spec.md`（训练侧规格）

## 背景与预期参照

纸面预算（2026-10-16，型号调查与公开规格核实）给出的预期：机械实用上限约 100 m/s²，软件注册表 `ACC_MAX` 上限 30000 mm/s²（30 m/s²）是第一道墙，机械约有 3 倍裕量。本实验验证该预算，重点覆盖纸面算不出的两处风险：轻载斩波驱动的中频共振区（约 40–120 mm/s）与高速段（顶速 550 mm/s，受步进中断实测可持续步频 ≈22 kHz 限制）矩频衰减后的真实边界。纸面数字是参照不是结论。

## 固定条件

| 项 | 值 | 依据 |
|---|---|---|
| 驱动电压 VM | 20 V | 2026-10-16 供电修订，板级耐压已核查（hardware.md §2） |
| 运行/保持电流 | 800 / 400 mA | 电机额定 0.9 A（标签核实），800 mA 已用 89%，不上调 |
| 细分 | 8（40 steps/mm = 25 µm/step） | settings 默认 |
| 驱动模式 | SpreadCycle | 固件上电默认 |
| 判定域 | 电机轴（AS5600 尾轴直装） | 已确认按电机域定义；皮带打滑与弹性伸长不在判定范围 |

## 判定规则

一个试探段 = 单速度单加速度档的一次对称往返：以目标速度 +v 加速、巡航、减速停稳，再以 −v 对称回程、停稳。对称往返的期望终点等于起点，因此**段后净偏移 = 往返累计失步量**（去程失步不会被回程抵消：指令位置累计了失步量，编码器实测位置未跟上）。

| 观测 | 判定 |
|---|---|
| 固件推 `MODE FAULT STEP_LOSS` | 该段失败（运行中指令位置与编码器实测位置偏差超过 `STEP_LOSS_UM`） |
| 停稳后净偏移（终点 `x_um` − 起点 `x_um`）> 300 µm | 该段失败（300 µm = 12 步） |
| 净偏移 100–300 µm | 该组合复测，3 段多数判定 |
| 净偏移 ≤ 100 µm 且无 FAULT | 该段通过 |

停稳判定：状态流 `vx_mm_s` 连续 10 拍（50 ms）为 0。静止位置噪声实测约 20 µm 量级，远低于 100 µm 判定线。`STEP_LOSS_UM` 保持默认 3000 µm 作为运行中兜底保护（收紧会在高速点引入采样滞后的误触发风险：550 mm/s 下 1 kHz 采样周期的位置滞后已达 550 µm 量级），主判定依靠段后净偏移。

## 实验矩阵与单段时序

巡航速度 4 点 × `ACC_MAX` 6 档，每组合 3 段往返：

- 速度点：50 / 120 / 300 / 550 mm/s（覆盖共振嫌疑段到中断步频顶速）
- `ACC_MAX`：5000 / 10000 / 15000 / 20000 / 25000 / 30000 mm/s²
- 执行顺序：速度从低到高、加速度从低到高；某档失败不中断矩阵（数据取完整矩阵），但出现连续 FAULT、异常噪声或温升异常时人工中止
- 时间预算：全程含标定与记录约 20–30 分钟（预估）

单方向巡航保持时间按单方向总位移（加速 + 巡航 + 减速）设计，数值按最不利档（最低加速度）计算：

| 巡航速度 (mm/s) | 单方向目标位移 (mm) | 加减速位移 v²/a（最不利档, mm） | 巡航保持 t_hold (s) |
|---|---|---|---|
| 50 | 60 | 0.5 | ≈1.2 |
| 120 | 80 | 2.9 | ≈0.64 |
| 300 | 100 | 18 | ≈0.27 |
| 550 | 150 | 60.5 | ≈0.16 |

运动范围单方向不超过 150 mm，位于软限位窗口（标定行程 600 mm、余量 10 mm 时窗口约 ±290 mm）内。

主机侧时序：每 50 ms 重发当前 `VEL` 值喂狗（`WDT_MS` 默认 100 ms）；段序列为设定 +v → 停稳判定 → 记录 `x_um` → 设定 −v → 停稳判定 → 记录 `x_um` 取净偏移。

## 前置条件

1. 20V 首检：3.3V 轨电压正常、TMC2209 散热板温升可接受（hardware.md §2 核查记录）。
2. 正式固件烧录当前分支构建产物。
3. 两点标定（`MARK LEFT` / `MARK RIGHT`），记录标定行程。
4. `CONFIG?` 存档参数快照（含默认值与实验期改动）。
5. 冒烟段：`ACC_MAX=5000`、50 mm/s 一次往返，确认命令链路与状态流记录通路。
6. 数据记录：UART1 状态流按 200 Hz 捕获全 session 日志，控制面命令与应答同文件记录；捕获脚本在执行阶段基于现有 host 工具提供（预估）。

## 附带测量：VEL 阶跃响应

矩阵之外，在 50 mm/s、`ACC_MAX=5000` 下记录 0 → 50 → 0 mm/s 的 `vx_mm_s` 时间序列（200 Hz），提取实际斜坡斜率与速度跟踪滞后。该项直接对应 cartpole 仓库 sim2real-spec.md 未决项「a_max、τ 待实机速度跟踪特性实测后修订」，作为训练侧执行器模型参数修订依据。

## 安全设计

- **软限位在失步后仍然有效**：钳制读编码器实测位置（cartfsm.c `clamp_and_commit_velocity` 调 `cartpos_position_um`），不依赖已漂移的指令位置——小车真实位置越出窗口即截断向外的速度分量。
- `STEP_LOSS_UM`（默认 3000 µm）运行中判据触发 FAULT：斜坡停机并关闭使能，为失控兜底。
- 升序执行 + 全程人工监视：异常时发 `VEL 0` 并 `RESET`。
- 运动范围限单方向 150 mm 内，两端余量充足。
