# 写作规则

本文件适用于项目文档、规格、计划、详细技术解释与评审报告，完整定义语言、表达和文档组织要求。

## 文档组织与职责

- 项目文档面向首次接触项目的维护者，以项目自身的行为、结构、约束和实施状态组织内容。概念首次出现时提供必要定义或对应文档引用，使读者仅凭文档即可理解和使用。

- 引用项目内其他文档或指定权威来源的代码文件时，直接给出 markdown 链接，减少读者检索成本。

- 每项文档规则在其责任专题完整定义，其他文档通过引用使用；实施进度由对应计划跟踪，验证记录注明日期、环境与范围。

编写规格或计划时同时遵守[设计与计划规则](design-and-planning.md)；评审报告同时遵守[评审规则](review.md)。
